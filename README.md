# Alètheia Srl - Bozzetto Next.js per Tema iTeach

Questo è un bozzetto realizzata con Next.js che mostra come i contenuti di Alètheia Srl apparirebbero applicando lo stile del tema WordPress iTeach.

## Scopo
Questo progetto serve come mockup da mostrare al proprietario del tema iTeach per dimostrare:
- Come i contenuti reali di Alètheia Srl si integrerebbero nello stile iTeach
- La struttura a blocchi, le card definite, i badge di categoria, le ombreggiature morbide
- La tipografia e la palette colori ispirate a iTeach

## Tecnologie Utilizzate
- Next.js 13.4.0
- React 18.2.0
- CSS3 puro (variabili CSS, Flexbox/Grid)
- Font Awesome 6.5.0 (tramite CDN)
- Google Fonts (Plus Jakarta Sans)

## Come Eseguire il Progetto Locale

1. **Clona o copia i file** in una cartella locale
2. **Installa le dipendenze**:
   ```bash
   npm install
   ```
3. **Avvia il server di sviluppo**:
   ```bash
   npm run dev
   ```
4. Apri [http://localhost:3000](http://localhost:3000) nel tuo browser

## Struttura del Progetto
```
aletheia-srl-next/
├── pages/
│   ├── _app.js          // Impostazioni globali (CSS, font)
│   └── index.js         // Pagina principale con tutte le sezioni
├── styles/

```

## Note Importanti
- Questo è **SOLO un bozzetto dimostrativo** - non è un tema WordPress funzionante
- Per utilizzare effettivamente lo stile iTeach, è necessario acquistare e installare il tema ufficiale su WordPress
- Questo mockup mostra come apparirebbero i contenuti di Alètheia Srl una volta applicato il tema iTeach
- Tutte le sezioni (header, hero, servizi, corsi in evidenza, e-learning, footer) sono presenti e responsive
- Il design utilizza esattamente le stesse variabili colori, tipografia e componenti visivi dello stile iTeach descritto nelle richieste

## Prossimi Passi Dopo l'Acquisto del Tema iTeach
1. Installare WordPress e il tema iTeach
2. Utilizzare il Customizer o Elementor Pro per ricreare questa struttura
3. Sostituire i contenuti placeholder con quelli reali di Alètheia Srl
